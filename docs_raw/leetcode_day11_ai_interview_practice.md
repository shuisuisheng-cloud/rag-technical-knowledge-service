# 题 1：移动零

## 源码

```text
leetcode/01_array/day11_move_zeroes.py
```

## 题意摘要

给定数组：

```text
把所有 0 移动到数组末尾
同时保持所有非零元素原来的相对顺序
不能额外创建一个长度为 n 的数组
```

要求原地处理。

---

## 我的实际完成情况

开始时没有完整思路，只判断这题可能与：

```text
双指针
```

有关。

在得到一级提示：

```text
一个指针负责扫描
一个指针表示下一个非零元素应该放的位置
```

之后，独立完成了后续交换逻辑。

最终理解两个指针职责：

```text
right
→ 从左向右扫描整个数组

left
→ 下一个非零元素应该放置的位置
```

处理规则：

```text
nums[right] == 0
→ 只继续移动 right

nums[right] != 0
→ 交换 nums[left] 和 nums[right]
→ left 前进
→ right 继续扫描
```

---

## 为什么不会改变非零元素相对顺序

`right` 始终按照：

```text
从左到右
```

扫描数组。

每发现一个非零元素，就把它放到：

```text
当前最靠左、应该存放非零元素的位置 left
```

因此非零元素被处理的先后顺序就是它们在原数组中的先后顺序。

不会发生后面的非零元素跑到前面的非零元素之前。

---

## 复杂度

时间复杂度：

```text
O(n)
```

数组只需要从左向右扫描一次。

额外空间复杂度：

```text
O(1)
```

只使用固定数量的指针变量，没有创建另一个长度为 n 的数组。

# 题 2：括号是否合法

## 源码

```text
leetcode/interview_practice/day11_valid_parentheses.py
```

## 题意摘要

输入只由：

```text
()
[]
{}
```

组成的字符串。

判断所有括号是否：

```text
类型正确
顺序正确
完整闭合
```

---

## 我的实际完成情况

这是第一次正式接触：

```text
栈
```

类型的算法题。

最开始尝试根据：

```text
相邻位置
对称位置
```

判断括号是否合法，但这种方法无法解决不同括号嵌套的问题。

经过提示后开始建立栈结构。

核心理解：

```text
左括号
→ 暂时等待之后的右括号匹配
→ 加入 waiting / stack

右括号
→ 必须匹配最近一个还没有被关闭的左括号
```

这正好对应：

```text
LIFO
Last In First Out
后进先出
```

---

## 栈在本题中的状态

Python 使用 `list` 模拟栈。

入栈：

```python
stack.append(x)
```

表示：

```text
新的左括号进入等待匹配状态
```

出栈：

```python
stack.pop()
```

表示：

```text
最近进入的左括号已经完成匹配
```

查看栈顶：

```python
stack[-1]
```

表示：

```text
查看最近一个等待匹配的左括号
但不删除它
```

---

## 两个关键非法情况

### 空栈遇到右括号

例如：

```text
")
```

此时不存在可以和它匹配的左括号。

因此立即失败。

### 遍历结束后栈不为空

例如：

```text
((()
```

说明：

```text
仍然存在没有被关闭的左括号
```

因此同样非法。

---

## 复杂度

时间复杂度：

```text
O(n)
```

每个字符最多进行一次入栈或出栈。

最坏额外空间复杂度：

```text
O(n)
```

例如全部都是左括号时：

```text
((((((((
```

所有字符都会进入栈。

# 题 3：向量余弦相似度

## 源码

```text
leetcode/ml_algorithm/01_math_basic/ml02_cosine_similarity.py
```

## 题意摘要

不使用 NumPy，手写两个向量的：

```text
Cosine Similarity
余弦相似度
```

如果任意一个向量是零向量：

```text
输出 0.000000
```

---

## 我的实际完成情况

核心计算主体基本独立完成。

自己拆出了三个累加量：

```text
点积
Σ(ai * bi)

A 的平方和
Σ(ai²)

B 的平方和
Σ(bi²)
```

也理解：

```text
点积
和
两个向量模长
```

是余弦相似度计算的核心组成部分。

---

## 最终公式

```text
cosine = dot / sqrt(norm_a_sq * norm_b_sq)
```

其中：

```text
dot
= Σ(ai * bi)

norm_a_sq
= Σ(ai²)

norm_b_sq
= Σ(bi²)
```

分母：

```text
sqrt(norm_a_sq * norm_b_sq)
```

等价于：

```text
|A| × |B|
```

---

## 今天被纠正的主要问题

### Python 的 `^` 不是平方

错误理解：

```python
x ^ 2
```

并不是：

```text
x²
```

Python 中：

```text
^
```

表示：

```text
按位异或 XOR
```

平方应使用：

```python
x ** 2
```

或者：

```python
x * x
```

---

### 分母需要开平方

如果只计算：

```text
norm_a_sq * norm_b_sq
```

得到的是：

```text
两个模长平方的乘积
```

而余弦相似度需要的是：

```text
|A| × |B|
```

因此需要：

```python
sqrt(norm_a_sq * norm_b_sq)
```

---

### 必须处理零向量

如果：

```text
A = [0, 0, 0]
```

那么：

```text
|A| = 0
```

直接计算：

```text
dot / (|A| × |B|)
```

会出现：

```text
除 0
```

因此如果任一向量模长为 0：

```text
cosine similarity = 0
```

按照题目要求输出：

```text
0.000000
```

---

### 输入应该使用 float

因为向量元素可能是：

```text
整数
也可能是小数
```

所以读取向量时应使用：

```python
float
```

而不是只按照：

```python
int
```

处理。

---

## 复杂度

时间复杂度：

```text
O(n)
```

一次遍历即可累计：

```text
dot
norm_a_sq
norm_b_sq
```

当前完整程序需要先读入：

```text
向量 A
向量 B
```

两个 list。

因此整体存储空间：

```text
O(n)
```

需要注意：

```text
核心余弦计算部分
```

本身只使用：

```text
dot
norm_a_sq
norm_b_sq
```

等固定数量累加变量。

但由于当前输入实现把完整向量保存在 list 中，所以整个程序不能写成 O(1) 空间。

# Python 易错点

## 1. `readline()` / `strip()` / `split()` / `map()` / `list()` 的区别

这些函数经常连续出现，但职责不同。

### `readline()`

```python
line = sys.stdin.readline()
```

作用：

```text
从标准输入读取一整行
```

返回：

```text
str
```

通常可能包含行尾换行符：

```text
\n
```

---

### `strip()`

```python
line.strip()
```

作用：

```text
删除字符串首尾的空白字符
```

例如：

```text
"1 2 3\n"
↓
"1 2 3"
```

仍然是：

```text
str
```

---

### `split()`

```python
line.split()
```

作用：

```text
按照空白把一个字符串切成多个字符串
```

例如：

```text
"1 2 3"
↓
["1", "2", "3"]
```

结果：

```text
list[str]
```

---

### `map()`

例如：

```python
map(float, ["1", "2.5", "3"])
```

作用：

```text
逐个应用 float()
```

概念结果：

```text
1.0
2.5
3.0
```

需要注意：

```text
map() 返回的是 map 迭代器
并不是直接返回 list
```

---

### `list()`

例如：

```python
list(map(float, line.split()))
```

作用：

```text
把 map 产生的结果真正收集到 list 中
```

最终：

```python
[1.0, 2.5, 3.0]
```

因此常见输入数据流：

```text
sys.stdin.readline()
↓
读取一行 str
↓
strip()
↓
去掉首尾空白
↓
split()
↓
list[str]
↓
map(float, ...)
↓
逐个转换
↓
list(...)
↓
list[float]
```

重点：

```text
每一步解决的问题不同
不要只把整句输入模板机械背下来
```

---

## 2. `^` 不是平方

Python：

```python
a ^ b
```

表示：

```text
按位异或 XOR
```

不是幂运算。

幂运算使用：

```python
a ** b
```

平方也可以：

```python
a * a
```

---

## 3. `set` / `list` 等容器操作要理解返回值和状态变化

不能只记：

```text
“这个方法好像是操作容器”
```

必须分清两个问题：

```text
这个操作会不会修改原容器？

这个操作的返回值是什么？
```

例如本次栈：

```python
stack.append(x)
```

主要作用：

```text
修改 stack
把 x 加到末尾
```

而：

```python
stack.pop()
```

既：

```text
修改 stack
删除最后一个元素
```

又：

```text
返回被删除的那个元素
```

而：

```python
stack[-1]
```

只：

```text
读取最后一个元素
```

不会删除。

以后遇到：

```text
list
set
dict
stack
```

相关操作时，都需要先明确：

```text
输入是什么
返回什么
原容器有没有改变
```

不能只根据函数名字猜行为。
